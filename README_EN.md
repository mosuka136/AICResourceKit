A resource replacement plugin and authoring toolkit for Alice In Cradle, built on BepInEx, Harmony, and UnityModBase.

Supports MTI and Unity Resources textures, PXL images and full pages, modular composition of the main character's Spine portrait, multi-page Spine assets for story scenes, and individual atlas region replacement. Resource packs can be reordered, enabled, disabled, and refreshed, with a setting to control access to sensitive content. Includes portrait previews, resource status and loading diagnostics, MPCC dependency inspection, and command-line inspection and encryption tools.

## Quick Start

1. Install BepInEx 5 and UnityModBase, then place `AICResourceKit.dll` in the game's `BepInEx/plugins/AICResourceKit/` directory.
2. Launch the game and select AICResourceKit in the UnityModBase configuration interface. The main switch, `EnableMod`, must be enabled at startup. If it was disabled when the game started, enable it and restart the game.
3. Place resource packs in `BepInEx/plugins/AICResourceKit/ReplaceTexture/`, turn on **Enable Resource Replacement**, and enable the packs you want in the list. Packs lower in the list take priority.
4. After editing resource files, press the default hotkey `Ctrl+T`, or choose **Refresh Resources** on the **Resources** page of the control interface. The same page lets you view loading results and export the current status.

The configuration file is located at `BepInEx/plugins/AICResourceKit/AICResourceKit.cfg`.

Installable manifests support `formatVersion: 2` and `3`. Version 3 adds [selective replacement](docs/portrait-selection.md) of main UI Spine/PXL portraits by pose or state, with base animation filtering for Spine. Unselected states use the original resources. BEREENC v1 encrypted resources remain compatible. Spine assets use straight-alpha PNGs and Spine 4.1 JSON. Main character portraits support a single atlas page; Spine assets for story scenes support multiple pages with explicit page mappings. See [capabilities.json](docs/resource-replacement/capabilities.json) for the capabilities of the compiled version.
